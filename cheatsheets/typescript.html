A practical TypeScript reference covering types, interfaces, functions, generics, classes, narrowing, utility types, modules, and common patterns.

TypeScript Basics

TypeScript adds static type checking and other features to JavaScript while compiling to JavaScript.

Basic Example 

let message: string = "Hello TypeScript";

console.log(message);

Compile TypeScript 

tsc app.ts

Run the JavaScript 

node app.js

any, unknown & never

any 

let value: any = 10;

value = "Hello";
value = true;

any disables most type checking for that value and should generally be used carefully.

unknown 

let value: unknown = "Hello";

if (typeof value === "string") {
    console.log(value.toUpperCase());
}

never 

function fail(message: string): never {
    throw new Error(message);
}

Type Narrowing

Type narrowing lets TypeScript determine a more specific type inside a particular block of code.

typeof 

function printValue(
    value: string | number
) {

    if (typeof value === "string") {
        console.log(value.toUpperCase());
    } else {
        console.log(value.toFixed(2));
    }

}

instanceof 

function printDate(
    value: Date | string
) {

    if (value instanceof Date) {
        console.log(value.toISOString());
    } else {
        console.log(value);
    }

}

Type Assertions

as Syntax 

const value: unknown = "Hello";

const message = value as string;

console.log(message.length);

Angle Bracket Syntax 

const value: unknown = "Hello";

const message = <string>value;

The as syntax is commonly preferred, especially in codebases that use JSX.

Generics

Generics allow reusable code to work with different types while preserving type information.

Generic Function 

function identity<T>(
    value: T
): T {
    return value;
}

const numberValue = identity(100);
const stringValue = identity("Hello");

Generic Array 

function first<T>(
    items: T[]
): T {
    return items[0];
}

const result = first([1, 2, 3]);

Generic Interface 

interface Box<T> {
    value: T;
}

const numberBox: Box<number> = {
    value: 100
};

keyof

The keyof operator creates a union of the property names of a type. 

interface User {
    name: string;
    age: number;
}

type UserKey = keyof User;

// "name" | "age"

Using keyof 

function getValue<T, K extends keyof T>(
    object: T,
    key: K
): T[K] {
    return object[key];
}

const user = {
    name: "Aryan",
    age: 20
};

const name = getValue(user, "name");

A tsconfig.json file defines compiler options for a TypeScript project.

Example

    "compilerOptions": {

        "strict": true,
        "esModuleInterop": true,
        "outDir": "./dist"

Quick Reference

  • string — text values
  • number — numeric values
  • boolean — true / false
  • interface — describe object structure
  • type — create type aliases
  • | — union types
  • & — intersection types
  • extends — inheritance or generic constraints
  • keyof — property keys of a type
  • Partial<T> — make properties optional
  • Pick<T, K> — select properties
  • Omit<T, K> — remove properties
  • Record<K, T> — create mapped object types
  • unknown — safely represent an unknown value
  • never — represents values that never occur
