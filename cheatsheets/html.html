HTML Cheatsheet

A practical reference for HTML elements, attributes, structure, forms, semantic markup, and more.

HTML Document Structure

The basic structure of an HTML document looks like this: 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

</body>

</html>

Common HTML Tags

Tag Purpose Example
<h1> Main heading <h1>Title</h1>
<p> Paragraph <p>Hello</p>
<a> Link <a href="#">Link</a>
<img> Image <img src="image.jpg" alt="Image">
<div> Generic block container <div>Content</div>
<span> Generic inline container <span>Text</span>
<ul> Unordered list <ul>...</ul>
<ol> Ordered list <ol>...</ol>
<li> List item <li>Item</li>

Forms & Inputs

<form action="/submit" method="post">

    <label for="name">Name</label>

    <input
        type="text"
        id="name"
        name="name"
        placeholder="Enter your name"
    >

    <button type="submit">
        Submit
    </button>

</form>

Common Input Types

  • text — Text input
  • email — Email address
  • password — Password
  • number — Numeric input
  • date — Date picker
  • checkbox — Checkbox
  • radio — Radio button
  • file — File upload
  • submit — Submit button

Semantic HTML

Semantic elements describe the meaning of their content.

Element Purpose
<header> Introductory content or navigation
<nav> Navigation links
<main> Main page content
<section> Thematic section of content
<article> Self-contained content
<aside> Related or secondary content
<footer> Footer information
