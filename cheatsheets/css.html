CSS Cheatsheet

CSS Basics

CSS controls the presentation and layout of HTML elements.

Connecting CSS 

<!-- External CSS -->
<link rel="stylesheet" href="style.css">

<!-- Internal CSS -->
<style>
    p {
        color: blue;
    }
</style>

<!-- Inline CSS -->
<p style="color: blue;">Hello</p>

Basic Rule Structure 

selector {
    property: value;
}

Example: 

p {
    color: blue;
    font-size: 18px;
}

Selectors

Selectors determine which HTML elements a CSS rule applies to.

Selector Example Targets
Element p All paragraph elements
Class .card Elements with class="card"
ID #header Element with id="header"
Universal * Every element
Attribute input[type="text"] Matching input elements
Descendant .card p Paragraphs inside .card
Child .card > p Direct child paragraphs
Adjacent sibling h2 + p First p immediately after h2

Pseudo-classes 

a:hover {
    color: blue;
}

input:focus {
    outline: 2px solid blue;
}

li:first-child {
    font-weight: bold;
}

li:last-child {
    margin-bottom: 0;
}

button:disabled {
    opacity: 0.5;
}

Pseudo-elements 

p::before {
    content: "→ ";
}

p::after {
    content: " ✓";
}

::selection {
    background: black;
    color: white;
}

Box Model

Every HTML element is represented as a box consisting of content, padding, border, and margin. 

.box {
    width: 300px;
    height: 200px;

    padding: 20px;

    border: 1px solid #ccc;

    margin: 30px;
}

Box Sizing 

/* Recommended global rule */

* {
    box-sizing: border-box;
}

With border-box, padding and borders are included in the declared width and height.

Flexbox

Flexbox is designed for arranging elements along one-dimensional rows or columns.

Container 

.container {
    display: flex;

    flex-direction: row;

    justify-content: center;

    align-items: center;

    gap: 20px;
}

Direction 

.container {
    display: flex;

    flex-direction: row;
}

/* Vertical */

.container {
    flex-direction: column;
}

Justify Content 

.container {
    display: flex;

    justify-content: flex-start;
    justify-content: center;
    justify-content: flex-end;
    justify-content: space-between;
    justify-content: space-around;
    justify-content: space-evenly;
}

Align Items 

.container {
    display: flex;

    align-items: stretch;
    align-items: flex-start;
    align-items: center;
    align-items: flex-end;
    align-items: baseline;
}

Wrapping 

.container {
    display: flex;

    flex-wrap: wrap;

    gap: 16px;
}

CSS Grid

CSS Grid is useful for two-dimensional layouts involving rows and columns.

Basic Grid 

.grid {
    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;
}

Responsive Grid 

.grid {
    display: grid;

    grid-template-columns:
        repeat(
            auto-fit,
            minmax(250px, 1fr)
        );

    gap: 20px;
}

Grid Placement 

.item {
    grid-column: span 2;
}

.feature {
    grid-row: span 2;
}

Positioning

Position Behavior
static Normal document flow
relative Offset relative to normal position
absolute Positioned relative to a containing block
fixed Positioned relative to the viewport
sticky Acts relative until a scroll threshold 
.parent {
    position: relative;
}

.child {
    position: absolute;

    top: 20px;
    right: 20px;
}

Responsive Design

Media queries allow styles to change based on viewport characteristics.

Media Query 

@media (max-width: 768px) {

    .container {
        padding: 20px;
    }

    .grid {
        grid-template-columns: 1fr;
    }

}

Common Breakpoints 

/* Small phones */
@media (max-width: 480px) {}

/* Tablets */
@media (max-width: 768px) {}

/* Laptops */
@media (max-width: 1024px) {}

/* Large screens */
@media (max-width: 1280px) {}

Transitions & Animations

Transition 

.button {
    background: blue;

    transition:
        background 0.2s ease,
        transform 0.2s ease;
}

.button:hover {
    background: darkblue;
    transform: translateY(-2px);
}

Transform 

.box {
    transform: translateX(20px);
}

.box {
    transform: scale(1.1);
}

.box {
    transform: rotate(45deg);
}

Keyframes 

@keyframes fadeIn {

    from {
        opacity: 0;
    }

    to {
        opacity: 1;
    }

}

.element {
    animation:
        fadeIn
        0.5s
        ease
        forwards;
}

CSS Variables

Custom properties make it easier to reuse values throughout a stylesheet. 

:root {
    --primary: #2563eb;
    --background: #ffffff;
    --text: #111827;
    --spacing: 20px;
}

.button {
    color: white;
    background: var(--primary);

    padding: var(--spacing);
}

body {
    color: var(--text);
    background: var(--background);
}

Changing a Variable 

:root {
    --primary: #7c3aed;
}
