MongoDB Cheatsheet

A practical reference for MongoDB databases, collections, CRUD operations, queries, operators, indexes, and aggregation.

MongoDB Basics

MongoDB is a document-oriented NoSQL database. Data is stored as BSON documents inside collections.

Concept MongoDB
Database Container for collections
Collection Container for documents
Document Record stored as BSON
Field Key-value pair inside a document
_id Unique identifier for a document

MongoDB Shell

The MongoDB Shell, commonly called mongosh, is used to interact with MongoDB from the command line. 

mongosh

Connect to a MongoDB Server 

mongosh "mongodb://localhost:27017"

Database Commands

Show Databases 

show dbs

Select a Database 

use myDatabase

MongoDB switches to the specified database. The database may not appear in show dbs until data is stored in it.

Show Current Database 

db

Drop Current Database 

db.dropDatabase()

Collections

Show Collections 

show collections

Create a Collection 

db.createCollection("users")

Drop a Collection 

db.users.drop()

Documents

MongoDB documents use JSON-like syntax. Internally, MongoDB stores documents as BSON. 

{
    name: "Aryan",
    age: 21,
    email: "aryan@example.com",
    skills: ["HTML", "CSS", "JavaScript"]
}

Documents can contain nested objects and arrays. 

{
    name: "Aryan",
    address: {
        city: "Chandigarh",
        country: "India"
    }
}

Insert One Document 

db.users.insertOne({
    name: "Aryan",
    age: 21,
    email: "aryan@example.com"
})

MongoDB automatically generates an _id value if one is not supplied.

Insert Many Documents 

db.users.insertMany([
    {
        name: "Aman",
        age: 22
    },
    {
        name: "Riya",
        age: 20
    },
    {
        name: "John",
        age: 25
    }
])

Find Documents

Find All 

db.users.find()

Find One 

db.users.findOne()

Find by Field 

db.users.find({
    age: 21
})

Find by Multiple Fields 

db.users.find({
    age: 21,
    country: "India"
})

Projection

Projection controls which fields are returned. 

db.users.find(
    {},
    {
        name: 1,
        email: 1
    }
)

The _id field is included by default unless explicitly excluded. 

db.users.find(
    {},
    {
        _id: 0,
        name: 1,
        email: 1
    }
)

Comparison Operators

Operator Meaning
$eq Equal
$ne Not equal
$gt Greater than
$gte Greater than or equal
$lt Less than
$lte Less than or equal
$in Matches any value in an array
$nin Matches values not in an array 
db.users.find({
    age: {
        $gte: 18
    }
})
db.users.find({
    age: {
        $gte: 18,
        $lte: 30
    }
})
db.users.find({
    country: {
        $in: ["India", "Canada", "Japan"]
    }
})

Logical Operators

Operator Purpose
$and All conditions must match
$or At least one condition must match
$not Negates a condition
$nor None of the conditions should match 
db.users.find({
    $or: [
        { age: 18 },
        { age: 21 }
    ]
})
db.users.find({
    $and: [
        { age: { $gte: 18 } },
        { country: "India" }
    ]
})

Check Whether a Field Exists 

db.users.find({
    phone: {
        $exists: true
    }
})
db.users.find({
    phone: {
        $exists: false
    }
})

Regular Expressions

Use regular expressions for pattern matching. 

db.users.find({
    name: {
        $regex: "^A"
    }
})

This example finds names beginning with the letter A.

Sort

Use 1 for ascending order and -1 for descending order. 

db.users.find().sort({
    age: 1
})
db.users.find().sort({
    age: -1
})

Limit and Skip

Limit 

db.users.find().limit(10)

Skip 

db.users.find().skip(10)

Pagination 

db.users.find()
    .skip(20)
    .limit(10)

Update One 

db.users.updateOne(
    {
        name: "Aryan"
    },
    {
        $set: {
            age: 22
        }
    }
)

Update Many 

db.users.updateMany(
    {
        country: "India"
    },
    {
        $set: {
            verified: true
        }
    }
)

Update Operators

Operator Purpose
$set Set a field value
$unset Remove a field
$inc Increment a number
$mul Multiply a number
$min Update if the new value is smaller
$max Update if the new value is larger
$rename Rename a field 
db.products.updateOne(
    {
        name: "Laptop"
    },
    {
        $inc: {
            stock: 5
        }
    }
)
db.users.updateOne(
    {
        name: "Aryan"
    },
    {
        $unset: {
            temporaryField: ""
        }
    }
)

Delete Documents

Delete One 

db.users.deleteOne({
    name: "Aryan"
})

Delete Many 

db.users.deleteMany({
    verified: false
})

Count Documents 

db.users.countDocuments()
db.users.countDocuments({
    country: "India"
})

Distinct Values

Return unique values for a field. 

db.users.distinct("country")

Upsert

With upsert: true, MongoDB inserts a document if no matching document exists. 

db.users.updateOne(
    {
        email: "aryan@example.com"
    },
    {
        $set: {
            name: "Aryan",
            age: 21
        }
    },
    {
        upsert: true
    }
)

Arrays

Match an Array Element 

db.users.find({
    skills: "JavaScript"
})

Add to an Array 

db.users.updateOne(
    {
        name: "Aryan"
    },
    {
        $push: {
            skills: "MongoDB"
        }
    }
)

Add Multiple Values 

db.users.updateOne(
    {
        name: "Aryan"
    },
    {
        $push: {
            skills: {
                $each: [
                    "MongoDB",
                    "Node.js"
                ]
            }
        }
    }
)

Remove an Array Value 

db.users.updateOne(
    {
        name: "Aryan"
    },
    {
        $pull: {
            skills: "MongoDB"
        }
    }
)

Embedded Documents

MongoDB supports nested documents. 

{
    name: "Aryan",
    address: {
        city: "Chandigarh",
        country: "India"
    }
}

Query nested fields using dot notation. 

db.users.find({
    "address.city": "Chandigarh"
})
db.users.find({
    "address.country": "India"
})

Indexes

Indexes can improve query performance by allowing MongoDB to locate matching documents more efficiently.

Create an Index 

db.users.createIndex({
    email: 1
})

Create a Descending Index 

db.users.createIndex({
    createdAt: -1
})

Unique Index 

db.users.createIndex(
    {
        email: 1
    },
    {
        unique: true
    }
)

List Indexes 

db.users.getIndexes()

Drop an Index 

db.users.dropIndex("email_1")

Aggregation

Aggregation processes documents through a pipeline of stages.

Basic Pipeline 

db.orders.aggregate([
    {
        $match: {
            status: "completed"
        }
    }
])

Group 

db.orders.aggregate([
    {
        $group: {
            _id: "$userId",
            total: {
                $sum: "$amount"
            }
        }
    }
])

Sort Aggregation Results 

db.orders.aggregate([
    {
        $group: {
            _id: "$userId",
            total: {
                $sum: "$amount"
            }
        }
    },
    {
        $sort: {
            total: -1
        }
    }
])

Common Aggregation Stages

Stage Purpose
$match Filter documents
$group Group documents
$sort Sort documents
$limit Limit results
$skip Skip documents
$project Choose or transform fields
$unwind Deconstruct an array field
$lookup Join with another collection

$lookup

$lookup can combine documents from another collection. 

db.orders.aggregate([
    {
        $lookup: {
            from: "users",
            localField: "userId",
            foreignField: "_id",
            as: "user"
        }
    }
])

Destructive Operations

Commands such as deleteMany(), drop(), and dropDatabase() can permanently remove data. 

db.users.deleteMany({})

db.users.drop()

db.dropDatabase()

Use destructive commands carefully, especially in production environments.

Common MongoDB Patterns

Find Adults 

db.users.find({
    age: {
        $gte: 18
    }
})

Find Recent Users 

db.users.find({
    createdAt: {
        $gte: new Date("2026-01-01")
    }
})

Sort by Newest 

db.users.find()
    .sort({
        createdAt: -1
    })

Search and Limit 

db.users.find({
    country: "India"
})
.sort({
    createdAt: -1
})
.limit(10)

Update a Counter 

db.products.updateOne(
    {
        _id: productId
    },
    {
        $inc: {
            views: 1
        }
    }
)
