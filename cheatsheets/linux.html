Linux Cheatsheet

Essential Linux terminal commands for files, directories, permissions, processes, networking, packages and everyday system administration.

Quick Reference

Command Purpose
pwd Show current directory
ls List files and directories
cd Change directory
mkdir Create a directory
touch Create an empty file
cp Copy files or directories
mv Move or rename files
rm Remove files or directories
cat Display file contents
grep Search text

Terminal Basics

Print Working Directory 

pwd

Shows the full path of your current directory.

List Files 

ls

List Detailed Information 

ls -l

Show Hidden Files 

ls -a

Detailed List Including Hidden Files 

ls -la

Directory Navigation

Change Directory 

cd directory

Go to Parent Directory 

cd ..

Go to Home Directory 

cd ~

Go to Root Directory 

cd /

Return to Previous Directory 

cd -

Files & Directories

Create a File 

touch file.txt

Create a Directory 

mkdir projects

Create Nested Directories 

mkdir -p projects/web/src

Copy a File 

cp file.txt backup.txt

Copy a Directory 

cp -r projects backup-projects

Move a File 

mv file.txt documents/

Rename a File 

mv old-name.txt new-name.txt

Remove a File 

rm file.txt

Remove an Empty Directory 

rmdir projects

Remove a Directory and Its Contents 

rm -r projects

Be especially careful with recursive deletion commands.

Reading Files

Display a File 

cat file.txt

Display With Line Numbers 

cat -n file.txt

View a Long File 

less file.txt

Press q to exit less.

Show the Beginning of a File 

head file.txt

Show the Last Lines 

tail file.txt

Follow a Changing Log File 

tail -f app.log

Searching

Find Files by Name 

find . -name "file.txt"

Find All HTML Files 

find . -name "*.html"

Search Text in a File 

grep "hello" file.txt

Search Recursively 

grep -r "hello" .

Case-Insensitive Search 

grep -i "hello" file.txt

File Permissions

Linux permissions control who can read, write or execute a file.

  • r — read
  • w — write
  • x — execute

View Permissions 

ls -l

Make a File Executable 

chmod +x script.sh

Numeric Permissions 

chmod 755 script.sh

Common Permission Values

Value Meaning
400 Owner can read
600 Owner can read and write
644 Owner read/write, others read
755 Owner full access, others read/execute
777 Read/write/execute for everyone

Avoid broad permissions such as 777 unless there is a specific reason to use them.

Ownership

Change File Owner 

sudo chown username file.txt

Change Owner Recursively 

sudo chown -R username directory/

Change Group 

sudo chgrp groupname file.txt

Processes

Show Running Processes 

ps

Show Detailed Processes 

ps aux

Interactive Process Viewer 

top

Find a Process 

ps aux | grep node

Terminate a Process 

kill PID

Force Terminate a Process 

kill -9 PID

Prefer normal termination first. Force termination should generally be used only when necessary.

Show Sizes of Items

Archives

tar -cf archive.tar directory/

Extract a tar Archive

Create a gzip-compressed Archive

Extract a gzip Archive 

tar -xzf archive.tar.gz

Create a ZIP File 

zip -r archive.zip directory/

Extract a ZIP File

Package Management

Package commands depend on the Linux distribution. The examples below use Debian and Ubuntu's APT system.

Update Package Information 

sudo apt update

Upgrade Installed Packages 

sudo apt upgrade

Install a Package 

sudo apt install package-name

Remove a Package 

sudo apt remove package-name

Search for a Package 

apt search package-name

Environment Variables

Show an Environment Variable 

echo $PATH

Show All Environment Variables 

printenv

Set a Variable for the Current Shell 

export APP_ENV=development

Read the Variable 

echo $APP_ENV

Pipes & Redirection

Pipe Output 

ls -la | grep ".html"

The pipe | sends the output of one command into another command.

Redirect Output to a File 

ls > files.txt

Append Output 

ls >> files.txt

Redirect Input 

command < input.txt

Redirect Errors 

command 2> errors.txt

Command History

Show History 

history

Search History 

history | grep git

Run a Previous Command 

!!

sudo

sudo runs a command with elevated privileges when your account is permitted to do so. 

sudo command

Example 

sudo apt update

Use elevated privileges only when necessary.

Useful Linux Symbols

Symbol Meaning
. Current directory
.. Parent directory
~ Home directory
/ Root directory
| Pipe output to another command
> Overwrite output file
>> Append to output file
* Wildcard matching multiple characters

Everyday Terminal Workflow 

# Check where you are
pwd

# See what's there
ls -la

# Enter a project
cd project

# Check files
ls

# Create a directory
mkdir src

# Create a file
touch index.html

# Read a file
cat index.html

# Search for files
find . -name "*.html"

Important Safety Rules

  • Be careful with rm and especially recursive deletion.
  • Understand a command before using sudo.
  • Avoid running commands copied from unknown sources.
  • Check the current directory before destructive operations.
  • Do not expose passwords, tokens or private keys in commands.
  • Use the least privilege necessary for administrative tasks.
