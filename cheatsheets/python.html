Exceptions

try / except

else / finally

    result = 10 / 2

except ZeroDivisionError:

else:
    print(result)

finally:
    print("Finished.")

Object-Oriented Programming

Class and Object 

class Person:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"Hello, {self.name}!")


person = Person("Aryan", 20)

person.greet()

Inheritance 

class Animal:

    def speak(self):
        print("Animal sound")


class Dog(Animal):

    def bark(self):
        print("Woof!")


dog = Dog()

dog.speak()
dog.bark()

  • input() — receive user input
  • if / elif / else — conditions
  • for — iterate over values
  • while — repeat while a condition is true
  • def — define a function
  • class — define a class
  • import — import a module
  • try / except — handle exceptions
  • with — manage resources such as files
