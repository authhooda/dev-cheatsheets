DATABASE

SQL Cheatsheet

A practical reference for querying, filtering, joining, grouping, modifying, and managing relational databases.

SQL Basics

SQL (Structured Query Language) is used to communicate with relational databases.

Command Purpose
SELECT Read data
INSERT Add data
UPDATE Modify data
DELETE Remove data
CREATE Create database objects
ALTER Modify database objects
DROP Delete database objects

SELECT

Retrieve data from a table. 

SELECT *
FROM users;
SELECT name, email
FROM users;
SELECT
    name AS username,
    email AS email_address
FROM users;

DISTINCT

Return only unique values. 

SELECT DISTINCT country
FROM users;
SELECT DISTINCT country, city
FROM users;

WHERE

Filter rows based on a condition. 

SELECT *
FROM users
WHERE age > 18;
SELECT *
FROM users
WHERE country = 'India';

Comparison Operators

Operator Meaning
= Equal
<> Not equal
> Greater than
< Less than
>= Greater than or equal
<= Less than or equal

AND, OR, NOT 

SELECT *
FROM users
WHERE age >= 18
AND country = 'India';
SELECT *
FROM users
WHERE country = 'India'
OR country = 'Canada';
SELECT *
FROM users
WHERE NOT country = 'India';

IN

Match a value against multiple possible values. 

SELECT *
FROM users
WHERE country IN ('India', 'Canada', 'Japan');

BETWEEN

Filter values within a range. 

SELECT *
FROM products
WHERE price BETWEEN 100 AND 500;

LIKE

Search for patterns in text. 

SELECT *
FROM users
WHERE name LIKE 'A%';
SELECT *
FROM users
WHERE name LIKE '%son';
SELECT *
FROM users
WHERE name LIKE '%ary%';
Pattern Meaning
A% Starts with A
%A Ends with A
%A% Contains A
_A% Second character is A

NULL

Use IS NULL and IS NOT NULL to test for NULL values. 

SELECT *
FROM users
WHERE phone IS NULL;
SELECT *
FROM users
WHERE phone IS NOT NULL;

ORDER BY

Sort query results. 

SELECT *
FROM users
ORDER BY name;
SELECT *
FROM users
ORDER BY age DESC;
SELECT *
FROM users
ORDER BY country ASC, name ASC;

LIMIT

Restrict the number of rows returned. 

SELECT *
FROM users
LIMIT 10;

Some database systems use different syntax for limiting or paginating results.

INSERT

Add new rows to a table. 

INSERT INTO users (name, email, age)
VALUES ('Aryan', 'aryan@example.com', 21);

Insert Multiple Rows 

INSERT INTO users (name, email)
VALUES
    ('Aman', 'aman@example.com'),
    ('Riya', 'riya@example.com'),
    ('John', 'john@example.com');

UPDATE

Modify existing rows. 

UPDATE users
SET age = 22
WHERE id = 1;

Always use an appropriate WHERE condition when updating specific rows.

DELETE

Remove rows from a table. 

DELETE FROM users
WHERE id = 1;

Without a WHERE clause, the statement can delete every row in the table.

Aggregate Functions

Function Purpose
COUNT() Count rows or values
SUM() Add values
AVG() Calculate average
MIN() Find minimum
MAX() Find maximum 
SELECT COUNT(*)
FROM users;
SELECT AVG(salary)
FROM employees;
SELECT MIN(price), MAX(price)
FROM products;
SELECT SUM(amount)
FROM orders;

GROUP BY

Group rows so aggregate functions can be calculated for each group. 

SELECT country, COUNT(*) AS user_count
FROM users
GROUP BY country;
SELECT department, AVG(salary) AS average_salary
FROM employees
GROUP BY department;

HAVING

Filter grouped results. 

SELECT country, COUNT(*) AS user_count
FROM users
GROUP BY country
HAVING COUNT(*) > 10;

WHERE filters rows before grouping, while HAVING filters groups after aggregation.

JOINs

JOINs combine related rows from multiple tables.

INNER JOIN

Returns matching rows from both tables. 

SELECT
    users.name,
    orders.amount
FROM users
INNER JOIN orders
    ON users.id = orders.user_id;

LEFT JOIN

Returns all rows from the left table and matching rows from the right table. 

SELECT
    users.name,
    orders.amount
FROM users
LEFT JOIN orders
    ON users.id = orders.user_id;

RIGHT JOIN

Returns all rows from the right table and matching rows from the left table. 

SELECT
    users.name,
    orders.amount
FROM users
RIGHT JOIN orders
    ON users.id = orders.user_id;

FULL OUTER JOIN

Returns matching rows plus unmatched rows from both tables where supported. 

SELECT
    users.name,
    orders.amount
FROM users
FULL OUTER JOIN orders
    ON users.id = orders.user_id;

JOIN Summary

JOIN Returns
INNER JOIN Matching rows from both tables
LEFT JOIN All left rows + matching right rows
RIGHT JOIN All right rows + matching left rows
FULL OUTER JOIN All rows from both tables

Aliases

Aliases give tables or columns temporary names within a query. 

SELECT
    u.name,
    u.email
FROM users AS u;
SELECT
    name AS username
FROM users;

Subqueries

A subquery is a query nested inside another query. 

SELECT name
FROM users
WHERE id IN (
    SELECT user_id
    FROM orders
);
SELECT *
FROM products
WHERE price > (
    SELECT AVG(price)
    FROM products
);

CTEs

Common Table Expressions use the WITH keyword to define a temporary named result set. 

WITH active_users AS (
    SELECT *
    FROM users
    WHERE active = true
)
SELECT *
FROM active_users;

Multiple CTEs 

WITH
active_users AS (
    SELECT *
    FROM users
    WHERE active = true
),
large_orders AS (
    SELECT *
    FROM orders
    WHERE amount > 1000
)
SELECT *
FROM active_users
JOIN large_orders
    ON active_users.id = large_orders.user_id;

CASE

Use CASE for conditional logic. 

SELECT
    name,
    CASE
        WHEN age >= 18 THEN 'Adult'
        ELSE 'Minor'
    END AS age_group
FROM users;

COALESCE

Return the first non-NULL value. 

SELECT
    name,
    COALESCE(phone, 'No phone number') AS phone
FROM users;

Constraints

Constraints define rules for data stored in tables.

Constraint Purpose
PRIMARY KEY Uniquely identifies rows
FOREIGN KEY References another table
NOT NULL Prevents NULL values
UNIQUE Requires unique values
CHECK Enforces a condition
DEFAULT Provides a default value

CREATE TABLE 

CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE,
    age INTEGER,
    created_at TIMESTAMP
);

ALTER TABLE

Add a Column 

ALTER TABLE users
ADD COLUMN phone VARCHAR(20);

Drop a Column 

ALTER TABLE users
DROP COLUMN phone;

Exact ALTER TABLE syntax can vary between database systems.

DROP TABLE

Delete a table and its data. 

DROP TABLE users;

Indexes

Indexes can improve the performance of searches and other queries involving indexed columns. 

CREATE INDEX idx_users_email
ON users(email);
DROP INDEX idx_users_email;

Indexes also consume storage and can add overhead to data modification operations.

Transactions

Transactions group database operations into a unit that can be committed or rolled back. 

BEGIN;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

UPDATE accounts
SET balance = balance + 100
WHERE id = 2;

COMMIT;

Rollback 

BEGIN;

DELETE FROM users
WHERE id = 10;

ROLLBACK;

Transaction commands and behavior can vary between database systems.

Common Query Order

A common SQL query is written in this order: 

SELECT
FROM
WHERE
GROUP BY
HAVING
ORDER BY
LIMIT

Example: 

SELECT
    country,
    COUNT(*) AS user_count
FROM users
WHERE active = true
GROUP BY country
HAVING COUNT(*) > 5
ORDER BY user_count DESC
LIMIT 10;

Common SQL Patterns

Count Rows 

SELECT COUNT(*)
FROM users;

Find Duplicate Values 

SELECT email, COUNT(*)
FROM users
GROUP BY email
HAVING COUNT(*) > 1;

Find the Highest Value 

SELECT MAX(price)
FROM products;

Find the Lowest Value 

SELECT MIN(price)
FROM products;

Sort and Get the First Rows 

SELECT *
FROM products
ORDER BY price DESC
LIMIT 10;

Filter by Multiple Values 

SELECT *
FROM users
WHERE country IN ('India', 'Japan', 'Canada');
