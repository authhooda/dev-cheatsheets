Text Processing

Regular Expressions

A practical Regex reference covering character classes, quantifiers, anchors, groups, lookarounds, flags, and common real-world patterns.

Regex Basics

A regular expression is a pattern used to search, match, validate, extract, or replace text.

Literal Text 

hello

Matches the exact sequence hello.

Example 

/hello/

JavaScript Example 

const pattern = /hello/;

console.log(
    pattern.test("hello world")
);

Character Classes

Pattern Meaning
. Any character except line terminators
\d A digit
\D A non-digit
\w Word character
\W Non-word character
\s Whitespace character
\S Non-whitespace character

Character Set 

[abc]

Matches one character from a, b, or c.

Character Range 

[a-z]
[A-Z]
[0-9]

Multiple Ranges 

[a-zA-Z0-9]

Negated Character Set 

[^0-9]

Matches a character that is not a digit.

Quantifiers

Pattern Meaning
* Zero or more
+ One or more
? Zero or one
{n} Exactly n times
{n,} At least n times
{n,m} Between n and m times

Zero or More 

ab*

Matches a, ab, abb, and so on.

One or More 

ab+

Optional 

colou?r

Matches both color and colour.

Exact Count 

\d{4}

Matches exactly four digits.

Range 

\d{2,4}

Matches between two and four digits.

Anchors

Pattern Meaning
^ Beginning of input or line
$ End of input or line
\b Word boundary
\B Non-word boundary

Start of String 

^Hello

End of String 

world$

Exact Match 

^hello$

Word Boundary 

\bcat\b

Matches the word cat without matching it as part of another word such as catalog.

Groups

Capturing Group 

(abc)

Multiple Groups 

(\d{4})-(\d{2})-(\d{2})

The groups can be used to extract the year, month, and day.

Non-Capturing Group 

(?:abc)

Named Capturing Group 

(?<year>\d{4})

Alternation

The | operator means "or".

Basic Example 

cat|dog

Matches either cat or dog.

With Groups 

(cat|dog)s

Matches cats or dogs.

Regex Flags

Flag Purpose
g Global matching
i Case-insensitive matching
m Multiline mode
s Dot matches line terminators
u Unicode mode
y Sticky matching
d Include match indices

Case-Insensitive 

/hello/i

Global 

/hello/g

Multiple Flags 

/hello/gi

Lookahead

Positive Lookahead 

\d+(?=USD)

Matches digits only when they are followed by USD.

Negative Lookahead 

\d+(?!USD)

Matches digits only when they are not followed by USD.

Lookbehind

Positive Lookbehind 

(?<=\$)\d+

Matches digits that are preceded by $.

Negative Lookbehind 

(?<!\$)\d+

Matches digits that are not preceded by $.

Greedy vs Lazy

Greedy 

.*

A greedy quantifier attempts to match as much text as possible.

Lazy 

.*?

A lazy quantifier attempts to match as little text as possible while still allowing the pattern to succeed.

Example 

<.*>

This can consume from the first < through the last > in the input. 

<.*?>

The lazy version stops at the earliest possible closing >.

Common Regex Patterns

Digits Only 

^\d+$

Letters Only 

^[A-Za-z]+$

Alphanumeric 

^[A-Za-z0-9]+$

Username 

^[A-Za-z0-9_]{3,20}$

^[^\s@]+@[^\s@]+\.[^\s@]+$

URL 

^https?:\/\/[^\s]+$

IPv4 Address 

^(?:\d{1,3}\.){3}\d{1,3}$

Date: YYYY-MM-DD

JavaScript Regex Methods

test() 

const regex = /\d+/;

console.log(
    regex.test("123")
);

match() 

const text = "I have 10 apples";

const result = text.match(/\d+/);

console.log(result);

matchAll() 

const text = "10 20 30";

const matches = [
    ...text.matchAll(/\d+/g)
];

console.log(matches);

replace() 

const text = "hello world";

const result = text.replace(
    /world/,
    "TypeScript"
);

console.log(result);

split() 

const text = "apple,banana,orange";

const fruits = text.split(/,/);

console.log(fruits);

Python Regex

Import re 

import re

Search 

result = re.search(
    r"\d+",
    "Age: 20"
)

print(result.group())

Find All 

numbers = re.findall(
    r"\d+",
    "10 20 30"
)

print(numbers)

Replace 

text = re.sub(
    r"\s+",
    "-",
    "hello world"
)

print(text)

How to Build a Regex

  1. Identify exactly what should match.
  2. Choose character classes such as \d, \w, or [A-Z].
  3. Add quantifiers such as +, *, or {n}.
  4. Add anchors when the complete input must match.
  5. Use groups when parts of the match need to be combined or captured.
  6. Add flags when matching behavior needs to change.
  7. Test the pattern against both valid and invalid examples.

Example 

^[A-Z][a-z]+$

This pattern requires a string to start with one uppercase letter followed by one or more lowercase letters and to contain nothing else.

Quick Reference

  • . — any character
  • \d — digit
  • \w — word character
  • \s — whitespace
  • [abc] — one of the listed characters
  • [^abc] — anything except listed characters
  • * — zero or more
  • + — one or more
  • ? — zero or one
  • {n} — exactly n times
  • ^ — beginning
  • $ — end
  • () — capturing group
  • (?:) — non-capturing group
  • | — OR
  • (?=) — positive lookahead
  • (?! ) — negative lookahead
  • (?<=) — positive lookbehind
  • (?<!) — negative lookbehind
