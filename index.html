Complete HTML Cheatsheet

Learn HTML tags, attributes, nesting, examples, and what the browser actually displays.

1. Basic HTML Structure

The basic structure of an HTML document.

<!DOCTYPE html> Declaration

Tells the browser that the document uses modern HTML.

Code 

<!DOCTYPE html>

Browser

Result

This declaration itself produces no visible content.

<html> Root

The root element containing the entire HTML document. 

<html lang="en">

    ...

</html>
What can go inside? Normally: <head> and <body>
<head> Metadata

Contains information about the webpage that usually isn't displayed directly. 

<head>

    <title>My Website</title>

    <meta charset="UTF-8">

    <link
        rel="stylesheet"
        href="style.css"
    >

</head>
Common children <title>, <meta>, <link>, <style>, <script>, <base>
<body> Content

Contains the visible content of the webpage. 

<body>

    <h1>Hello World</h1>

    <p>
        Welcome to my website.
    </p>

</body>

    }

6. Images & Media

Add images, audio, video and external content.

<img> Void

Displays an image. 

<img
    src="cat.jpg"
    alt="A cat"
    width="300"
>
Browser

The actual image specified by src will appear here.

Important <img> cannot contain children.
<figure> Media

Groups self-contained media or content, often with a caption. 

<figure>

    <img
        src="mountain.jpg"
        alt="Mountain"
    >

    <figcaption>
        Mountain landscape
    </figcaption>

</figure>
Common children <img> and <figcaption>
<audio> Media

Embeds audio. 

<audio controls>

    <source
        src="music.mp3"
        type="audio/mpeg"
    >

</audio>
<video> Media

Embeds video. 

<video controls width="500">

    <source
        src="movie.mp4"
        type="video/mp4"
    >

</video>
<iframe> Embed

Embeds another webpage or document. 

<iframe
    src="https://example.com"
    width="600"
    height="400"
></iframe>

7. Lists

Create ordered, unordered and description lists.

<ul> List

Creates an unordered/bullet list. 

<ul>

    <li>Apple</li>
    <li>Banana</li>
    <li>Mango</li>

</ul>
  • Apple
  • Banana
  • Mango
What can go inside? Normally <li> elements.
<ol> List

Creates an ordered/numbered list. 

<ol>

    <li>First</li>
    <li>Second</li>
    <li>Third</li>

</ol>
  1. First
  2. Second
  3. Third
<li> List Item

Represents one item inside a list. 

<li>
    Apple
</li>
Usually used inside <ul>, <ol>, or <menu>.
<dl> / <dt> / <dd> Description List

Used for terms and their descriptions. 

<dl>

    <dt>HTML</dt>

    <dd>
        HyperText Markup Language
    </dd>

    <dt>CSS</dt>

    <dd>
        Cascading Style Sheets
    </dd>

</dl>
HTML
HyperText Markup Language
CSS
Cascading Style Sheets

8. Semantic Layout

Use meaningful HTML elements to describe the structure of a page.

<header> Semantic

Introductory content for a page or section. 

<header>

    <h1>My Website</h1>

    <nav>
        ...
    </nav>

</header>
<nav> Semantic

Contains navigation links. 

<nav>

    <a href="/">Home</a>

    <a href="/about">
        About
    </a>

    <a href="/contact">
        Contact
    </a>

</nav>
<main> Semantic

Contains the primary content of the document. 

<main>

    <h1>Products</h1>

    <p>
        Our products...
    </p>

</main>
<section> Semantic

Represents a thematic section of content. 

<section>

    <h2>About Us</h2>

    <p>
        We build websites.
    </p>

</section>
<article> Semantic

Represents self-contained content such as a blog post, news article, or forum post. 

<article>

    <h2>
        HTML Tutorial
    </h2>

    <p>
        HTML is a markup language.
    </p>

</article>
<aside> Semantic

Contains content related to the main content, such as a sidebar. 

<aside>

    <h2>
        Related Articles
    </h2>

    <a href="#">
        HTML Basics
    </a>

</aside>
<footer> Semantic

Footer for a page or section. 

<footer>

    <p>
        © 2026 My Website
    </p>

</footer>

14. HTML Nesting

HTML elements are placed inside other elements to create a document tree.

Think of HTML as a tree. Elements can contain other elements, just like folders contain files.
html
├── head
│ ├── title
│ ├── meta
│ └── link
│
└── body
   ├── header
   │ ├── h1
   │ └── nav
   │
   ├── main
   │ ├── section
   │ │ ├── h2
   │ │ └── p
   │ │
   │ └── article
   │
   └── footer
Example 
<div>

    <h1>
        Hello
    </h1>

    <p>
        Welcome
        <strong>
            to my website
        </strong>
    </p>

</div>
Tree div
├── h1
│ └── "Hello"
│
└── p
   ├── "Welcome"
   └── strong
      └── "to my website"

16. Deprecated / Obsolete Tags

You may encounter these in old HTML code. Avoid using them in new projects.

Don't use these for new websites. Modern HTML uses semantic elements and CSS instead.
Old element Modern approach
<center> CSS text-align
<font> CSS
<big> CSS
<strike> <s> or CSS
<tt> <code> or CSS
<acronym> <abbr>
<frame> Modern layout / iframe where appropriate
<frameset> Modern layout
<marquee> CSS animations
